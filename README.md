## 📋 Sobre o Projeto
Sistema desenvolvido para auxiliar usuários a estimarem de forma simples quanto gasto de energia elétrica um determinado aparelho consome por mês.

## 🧮 Fórmula Utilizada
O cálculo do consumo mensal em kWh é feito através da seguinte fórmula:
$$\text{consumoMensal} = \frac{\text{potencia} \times \text{horasDia} \times 30}{1000}$$
